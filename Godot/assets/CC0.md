# CC0 assets

Highway Renegade uses public-domain (CC0) textures and kits so the world is not a field of untextured primitives. Bike GLBs with `wheel_f` / `cockpit_cam` stay the Blender hero rigs.

## Poly Haven (CC0)

2K JPG maps (`_Diffuse`, `_nor_gl`, `_arm`) from [polyhaven.com](https://polyhaven.com):

| Asset | Use |
| --- | --- |
| [painted_worn_brick](https://polyhaven.com/a/painted_worn_brick) | City sidewalks |
| [rectangular_facade_tiles_02](https://polyhaven.com/a/rectangular_facade_tiles_02) | Billboard faces |
| [painted_plaster_wall](https://polyhaven.com/a/painted_plaster_wall) | Fallback city blocks, sheds |
| [sand_01](https://polyhaven.com/a/sand_01) | Desert ground / banks |
| [coast_sand_04](https://polyhaven.com/a/coast_sand_04) | Coast ground / banks |
| [rock_face](https://polyhaven.com/a/rock_face) | Mountain ground, tunnel |
| [rubber_tiles](https://polyhaven.com/a/rubber_tiles) | Tyre materials |
| [metal_plate](https://polyhaven.com/a/metal_plate) | Chrome / pumps |
| [leather_red_02](https://polyhaven.com/a/leather_red_02) | Rider suits (tinted per gang) |

Older asphalt, concrete, grass, and rust maps already in this folder are also Poly Haven CC0.

## Kenney (CC0)

GLTF kits from [kenney.nl](https://kenney.nl) (CC0 1.0):

- [Car Kit](https://kenney.nl/assets/car-kit) — traffic and parked cars
- [City Kit (Commercial)](https://kenney.nl/assets/city-kit-commercial) — shops, towers, horizon blocks
- [Nature Kit](https://kenney.nl/assets/nature-kit) — trees, palms, pines, rocks, cactus
